# OpenCodex v0.4.3

## 新功能

- 设置中心改为左侧小栏布局，分为「模型与 CLI 搭配」「终端显示」「关于」。
- 支持多个模型档案，并为 Claude Code、Codex、Aider 分别搭配经过校验的协议档案。
- 设置中心和项目「+」菜单均可按已保存的搭配启动；会话顶栏会显示实际使用的档案名。
- 未搭配的 CLI 始终沿用自身配置。Hermes、Gemini CLI、OpenCode 暂不提供档案启动，避免认证态或 provider 无法确定时误用个人账号。

## 安全边界

- OpenCodex 只写自身 `portable-data/config.json` 或 `~/.opencodex/config.json`，不改写任何 CLI 的配置、登录态或系统环境变量。
- 显式档案启动由后端直接构造程序参数和临时环境；密钥不进入命令行、任务记录或前端事件。
- 档案缺失、协议不匹配或参数无效时拒绝启动，不静默退回 CLI 自身账号。
- 终端只统一字号，不覆盖各 CLI 的 TUI 颜色和外观。

## 已开放协议

- Claude Code：Anthropic Messages
- Codex：OpenAI Responses
- Aider：OpenAI Chat Completions
