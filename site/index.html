CliFleet is a ~3 MB native window for running Claude Code, Codex, opencode or any other CLI side by side — one tab per agent, one folder per project. No Node runtime, no localhost server, and it never touches your CLI config. CliFleet 是一个约 3 MB 的原生窗口：Claude Code、Codex、opencode 或任意 CLI 并排跑——一个 agent 一个标签，一个文件夹一个项目。不用装 Node、不起本地服务、不碰你的 CLI 配置。

What it does, and what it deliberately doesn't 它做什么，以及它故意不做什么

01

Real terminals, kept alive真终端，进程保活

Every tab is a real PTY rendered by xterm.js with WebGL. Switching tabs or projects never kills a running agent — come back and the output is still scrolling. 每个标签都是真 PTY，xterm.js + WebGL 渲染。切标签、切项目都不杀进程——切回来输出还在滚。

02

Closing a tab cleans up关标签就清干净

Closing kills the whole child process tree — session kill on Unix, taskkill /T on Windows. No orphaned node or claude processes piling up after a day of parallel sessions. 关闭时连子进程树一起清——Unix 按会话杀，Windows 走 taskkill /T。跑一天并行会话也不留孤儿 node / claude 进程。

03

Portable, and hands off便携，不插手

Data can live next to the exe on a USB stick. No telemetry, no model or proxy injection, and PATH fallback dirs are appended — never prepended, so your preferred CLI keeps priority. 数据可以跟着 exe 放 U 盘。无遥测、不注入模型/代理变量；PATH 兜底目录只追加不前置，你优先装的 CLI 永远优先。

Paired with U-King配合 U-King 用更方便

U-King is the setup side of the same workflow: it detects and installs the AI CLIs, keeps your model endpoints in order, and manages each tool's own configuration. CliFleet is the daily driver — it opens the window, holds the terminals, and gets out of the way. They don't overlap and they don't fight over your config: U-King configures, CliFleet just runs what's already configured. U-King 是同一套流程里「装」的那一半：它负责识别并安装 AI CLI、把模型端点理清楚、管好每个工具自己的配置。CliFleet 是每天用的那一半：开窗、托管终端，然后消失。两者不重叠、也不抢配置——U-King 负责配好，CliFleet 负责把已经配好的跑起来。

  • → Both are open source and local-only: no accounts, no relay, no telemetry. 两个都开源、都纯本地：不用登录、不经中转、无遥测。

Install安装

One line, or ask your AI agent to do it. Every build is produced by GitHub Actions from this repository. 一行命令，或者让你的 AI 助手代劳。每个构建都由 GitHub Actions 从本仓库直接产出。

Windows
irm https://u-claw.org.cn/clifleet/install.ps1 | iex

Downloads the portable build, checks SHA256, installs to %LOCALAPPDATA%\\Programs\\CliFleet, adds a Start Menu shortcut. 下载绿色版、校验 SHA256、装到 %LOCALAPPDATA%\\Programs\\CliFleet，并建开始菜单快捷方式。

macOS / Linux
curl -fsSL https://u-claw.org.cn/clifleet/install.sh | sh

macOS: downloads the DMG and copies the app to /Applications. Linux: puts the AppImage at ~/.local/bin/clifleet. macOS：下载 DMG 并拷到 /Applications；Linux：把 AppImage 放到 ~/.local/bin/clifleet。

Portable (green) build: create a desktop shortcut绿色版：一键生成桌面快捷方式
irm https://u-claw.org.cn/clifleet/shortcut.ps1 | iex

Unzip anywhere, run that one line, and you get Desktop\CliFleet.lnk + a Start Menu entry — no install, no registry, no admin rights. Portable copies in a custom folder: add -Exe "D:\CliFleet\CliFleet.exe" (download the script to a file first). The portable ZIP also ships Create-Desktop-Shortcut.cmd — just double-click it. 解压到任意目录，跑这一行就得到 桌面\CliFleet.lnk 和开始菜单项——不安装、不写注册表、不要管理员权限。放在自定义目录的绿色版：先下载脚本到本地再加 -Exe "D:\CliFleet\CliFleet.exe"。绿色版 ZIP 里也自带 Create-Desktop-Shortcut.cmd，双击即可。
