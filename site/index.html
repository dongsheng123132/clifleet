CliFleet is a ~3 MB native window for running Claude Code, Codex, opencode or any other CLI side by side — one tab per agent, one folder per project. No Node runtime, no localhost server, and it never touches your CLI config. CliFleet 是一个约 3 MB 的原生窗口：Claude Code、Codex、opencode 或任意 CLI 并排跑——一个 agent 一个标签，一个文件夹一个项目。不用装 Node、不起本地服务、不碰你的 CLI 配置。

What it does, and what it deliberately doesn't 它做什么，以及它故意不做什么

01

Real terminals, kept alive真终端，进程保活

Every tab is a real PTY rendered by xterm.js with WebGL. Switching tabs or projects never kills a running agent — come back and the output is still scrolling. 每个标签都是真 PTY，xterm.js + WebGL 渲染。切标签、切项目都不杀进程——切回来输出还在滚。

02

Closing a tab cleans up关标签就清干净

Closing kills the whole child process tree — session kill on Unix, taskkill /T on Windows. No orphaned node or claude processes piling up after a day of parallel sessions. 关闭时连子进程树一起清——Unix 按会话杀，Windows 走 taskkill /T。跑一天并行会话也不留孤儿 node / claude 进程。

03

Portable, and hands off便携，不插手

Data can live next to the exe on a USB stick. No telemetry, no model or proxy injection, and PATH fallback dirs are appended — never prepended, so your preferred CLI keeps priority. 数据可以跟着 exe 放 U 盘。无遥测、不注入模型/代理变量；PATH 兜底目录只追加不前置，你优先装的 CLI 永远优先。
