Which AI coding terminal should you run? AI 编程终端，到底该用哪一个？

cmux, Conductor, Claude Squad, Emdash and CliFleet look similar in a screenshot and behave very differently over a full working day. This page breaks down the actual trade-offs — and it also lists the places where CliFleet is the weaker choice. cmux、Conductor、Claude Squad、Emdash 和 CliFleet 在截图里看着差不多，真用一天完全是另一回事。下面按实际取舍拆开讲，也包括 CliFleet 输的地方。

One-line verdict一句话结论

  • Windows / USB stick / one window only → CliFleet. Real terminals in tabs, nothing else. Windows / U 盘 / 只要一个窗口 → CliFleet。标签页里全是真终端，没有别的。
  • macOS native, notification ring, split panes → cmux. Built for keeping an eye on several agents at once. macOS 原生、通知环、分屏 → cmux。就是为了一眼盯住好几个 agent 做的。
  • Orchestration, diffs, PR review, cloud sandbox → Conductor or Emdash. They manage the work, not just the window. 编排、diff、PR review、云沙箱 → Conductor 或 Emdash。它们管的是活，不只是窗口。
  • Terminal TUI + tmux + worktrees → Claude Squad. Stays inside the shell you already live in. 终端 TUI + tmux + worktree → Claude Squad。不离开你本来就在用的 shell。

Where CliFleet deliberately loses CliFleet 刻意不做、因此落后的地方

Four limits worth knowing before you download it. 下载之前，这四条最好先知道。

01

No orchestration没有编排

No worktrees, no task queue, no automatic hand-off between agents. It gives you tabs, not a team that divides the work for you. 不做 worktree，没有任务队列，也不会在 agent 之间自动交接。它给你一排标签页，不是一个替你分工的团队。

02

No cloud, mobile, browser or diff panel 没有云、手机端、浏览器和 diff 面板

There is no remote sandbox and no phone app. No built-in browser either, and no diff review panel — you review with git, in the terminal, like before. 没有云沙箱，没有手机端，也没有内置浏览器和 diff review 面板——review 还是回到终端里用 git 做。

03

macOS build is not notarizedmacOS 包没有公证

The current macOS build is ad-hoc signed and not notarized. On first launch you have to approve it yourself in System Settings. macOS 包目前是 ad-hoc 签名、没做公证，第一次打开得自己去「系统设置 → 隐私与安全性」点「仍要打开」。

04

Still 0.x, with a small user base版本还是 0.x，用户也少

Fewer users means far fewer eyes on bugs than cmux or Conductor have. If you need a battle-tested tool today, pick one of those. 用户少，帮你发现 bug 的眼睛就远不如 cmux 或 Conductor 多。今天就要一个被大量使用磨过的工具，选它们更稳。

FAQ常见问题

Is CliFleet a terminal emulator? CliFleet 是终端模拟器吗？

Yes. Every tab is a real PTY rendered with xterm.js, so any CLI runs unchanged — no adapters, no wrappers. 是。每个标签背后都是一个真实 PTY，用 xterm.js 渲染，任何 CLI 都能原样跑，不需要适配或包装。

Does it work on Windows? Windows 能用吗？

Yes. Windows 10/11 is a first-class target. That is different from cmux and Conductor, which are macOS-only, and from Claude Squad, which depends on tmux. 能。Windows 10/11 是一等目标，这点和 cmux、Conductor（只支持 macOS）以及依赖 tmux 的 Claude Squad 不一样。

Can I run it from a USB stick? 能从 U 盘直接跑吗？

Yes. Your data travels with the exe: no install, no admin rights, and nothing left behind on the host machine. 可以。数据跟着 exe 走，不用安装、不要管理员权限，拔掉盘之后主机上也不留东西。

Do I need Node or a local server? 需要 Node 或本地服务吗？

No. It is one ~3 MB native binary that reuses the system WebView. No Node runtime, no background service, no port to open. 不需要。一个约 3 MB 的原生程序，复用系统 WebView；没有 Node 运行时，没有后台服务，也不用开端口。

Will it change my Claude Code / Codex config? 会改我的 Claude Code / Codex 配置吗？

No. It ships no keys, injects no model or proxy settings, and does not touch ~/.claude. The CLI inherits your environment exactly as it is. 不会。它不带 Key、不注入模型或代理设置，也不改 ~/.claude；CLI 拿到的就是你原来的环境。

Try CliFleet — 3 MB, one command 试试 CliFleet —— 3 MB，一条命令

Portable, native, MIT. Windows / macOS / Linux. If it is not for you, uninstalling is just deleting one file. 便携、原生、MIT，Windows / macOS / Linux 都能跑。不合适的话，卸载就是删掉一个文件。
